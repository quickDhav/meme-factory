# Meme Factory

### Where Humor Meets Creativity

---

## Overview

Meme Factory is a dynamic and interactive meme browser that brings the internet’s most popular meme templates into one place.

The project allows users to explore, search, and create memes through a clean and responsive interface.

---

## Features

**Smart Meme Search**
Search from a wide collection of popular meme templates instantly.

**Masonry Grid Layout**
Inspired by Pinterest, the UI adapts to different image sizes for a clean and structured layout.

**Category Tabs**
Browse memes by categories for a more organized experience.

**Share Functionality**
Copy meme links to clipboard with a single click for easy sharing.

**Back to Top Button**
Improves navigation and enhances user experience.

**Meme Creator Preview**
Users can type text into input fields and see it appear live on the meme image, simulating a real meme generator.

---

## Tech Stack

* Frontend: HTML, CSS, JavaScript
* API: Imgflip Meme API
* Design Concept: Responsive and Masonry Layout

---

## API Used

Public API from Imgflip:
https://imgflip.com/api

This API provides meme templates, image URLs, and related metadata.

---

## How It Works

1. Fetch memes from the API
2. Display them in a responsive grid layout
3. Enable search and filtering
4. Provide live meme text preview
5. Allow users to share meme links
